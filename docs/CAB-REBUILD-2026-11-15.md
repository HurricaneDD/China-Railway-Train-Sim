# 参照 Japan Rail Sim 的三维驾驶舱重构

仓库：[HurricaneDD/China-Railway-Train-Sim](https://github.com/HurricaneDD/China-Railway-Train-Sim)，分支 `drive`，基线 `5f4f6a2`。本次工作按用户反馈替代上一版 CSS 驾驶室；上一轮的记录保留为历史，不再代表当前座舱。

## 参考与实现

参考实际源码与最新官方截图：[驾驶舱几何](https://github.com/alzin/japan-rail-sim/blob/master/src/render/train/cab.ts)、[相机与更新循环](https://github.com/alzin/japan-rail-sim/blob/master/src/main.ts)、[最新驾驶室截图](https://raw.githubusercontent.com/alzin/japan-rail-sim/master/docs/cab-view.jpg)。根目录旧 `docs-cab-view.jpg` 没有用作目标。

关键参考是相机与真实三维内饰的相对关系：左偏 0.55 m、眼高 2.15 m，眼前约 1 m 是挡风玻璃；55° 为竖直视场，视线相对车体向前 60 m、向下 4 m。上一版的 58° 横向视场和屏幕外 CSS 窗框没有形成这种关系。

本项目自行生成米制座舱几何，沿用 Cesium，没有引入 Three.js，也没有复制日本车辆的动力学/供电/信号规则。它是通用演示座舱，非 E235 或中国特定机车型号的精确复刻。

- `cabGeometry.ts`：车体局部 X 为右、Y 为前、Z 为轨面以上高度；实体侧墙、窗框、窗台、倾斜台面、显示器外壳、圆形表、雨刷、按钮与操纵手柄。为现有驾驶显示区略调仪表/手柄的布局，保留参考的近距透视。
- `cameraPose.ts`：相机眼点、方向、上向量及座舱共享一个车体世界矩阵；左偏 0.55 m、眼高 2.15 m、玻璃前距 1 m、55°竖直 FOV、约 -3.81°车体相对俯角。坡度和转弯作用于同一坐标系。
- `CabRenderer.ts`：3 个 Primitive 分别管理内饰、动态手柄和显示器。显示器使用 768×192 的双画布纹理图集，每 100 ms 更新真实速度、牵引、实际制动、列车管压、方向和运行时间，圆表指针同样读取速度；没有虚构允许速度或信号。操纵仍使用侧栏和原键位。
- `CesiumMap.ts`：相机与座舱在 `scene.preUpdate` 同步，避免独立 rAF 在快速移动时造成渲染帧错位。近裁剪面 0.15 m，离开驾驶室恢复 1 m；外部视角隐藏全部内饰，Viewer 销毁时释放图元、材质纹理与画布。
- `DrivingHud.vue / style.css`：删除 CSS 假窗框/空白驾驶台及其画布裁切，三维座舱使用完整驾驶显示区。顶部菜单、侧栏仪表、控制、行程栏、设置和存档流程继续保留。

## 两个渲染问题

Cesium 的隐藏 Primitive 仍可能预建几何。默认兼容二维/Columbus 视图的管线会把本地米制座舱按 ECEF 做经度切分/投影，导致局部模型不显示。Viewer 现设 `scene3DOnly:true`，与本应用本来仅有三维地图的范围一致。

独立相机 rAF 会使渲染使用的包围球和眼点在快速运动时错帧，造成近处座舱被裁掉。相机和座舱改为在 Cesium 更新前同步；仪表面另向驾驶员前移，避免被其实体外壳挡住。近裁剪面同时降低，不能只扩大 FOV。

## 验证

- `npm test`：22 文件、116 项全部通过；`npm run build` 类型检查及静态多页面构建成功。
- 新增/更新眼点与玻璃距离、任意航向/坡度的共同坐标系、55°竖直 FOV、屏幕布局、真实仪表值与 10Hz 节流、固定图元/画布数量、隐藏及销毁测试。
- Chromium 起步后观察 3 秒，前进约 37.2 m；181 个 postRender 帧中座舱命令缺失 0 帧，总 Primitive 约 54、座舱近裁剪 0.15 m。这是短时可见性检查，不是全国长途或设备性能承诺。
- 生产构建的可见浏览器从南京南车站出发，检查实体驾驶台、实时仪表以及驾驶室/自由/固定三个视角切换。检查 1440×900 和 390×844 视口；截图为 `output/playwright/cab-japan-reference-desktop.png`、`cab-japan-reference-mobile.png`。开发版也验证了松开驻车、实际牵引起步和运动中的座舱可见性。

## 边界

没有加入头部自由观察、真实车型内饰、真实车体悬挂、座椅调节或可操作雨刷。三维手柄随操纵变化，尚不能直接拖动三维模型；原侧栏/键盘保持可操作。竖屏保留光学视场，会裁掉部分横向仪表，完整仪表可由侧栏查看；未进行真实手机测试。

本轮不包含站房、站台、真实桥面和隧道纵断面；沿用原有程序化轨旁环境。桥隧/地形不匹配、原始路网缺口等限制继续存在。未重新执行完整存档导入导出与全国长途金路径，也未把本地截图当作远端 Pages 或真实设备证据。

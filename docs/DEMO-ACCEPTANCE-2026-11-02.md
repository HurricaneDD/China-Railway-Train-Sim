# Demo 0.2 验收记录 — 2026-11-02

本轮实现全国自由驾驶入口，保留全部原始数据；不代表全国任意方向都已连续驾驶验收。

## 已完成

- 全国搜站、33 份分省数据按需加载、地图选点事件透传与手机选点模式。
- 原始端点接入其他折线已有内部顶点；仅在内存维护连接位置、有向出口，原始坐标、区段 ID 和累计里程不变。不把没有共享原始顶点的二维交叉或缺口擅自接通。
- 空间索引覆盖线段穿越范围，附近区段按距离排序，跨省相同几何 ID 别名，显式邻省预载。
- 修复低速历史吞点、往返编组位置、倒车跨节点、分岔回调、折返改走支线残留历史；跨行程异步结果隔离。
- 默认驻车，暂停/继续、操作引导、设置暂停、失焦释放输入、行程与直线邻站距离、第一公里停车练习、端点提示与重新检查入口。
- 地图先用基础地球启动，后台加载地形/影像；失败可降级重试。地形采样整次 12 秒时限、未知高程不冒充已测零高程，轨道就绪后替换旧图。增加合批道床与附近密集轨枕。
- IndexedDB 等待事务完成，校验历史与地理范围；同 ID 导入另存副本。存档仍为 V1。
- 机车保持长20、宽3.3、高4.7米，长轴平行铁轨。收尾按用户反馈将驾驶室视点从轨面上方3.2米降至2.2米，俯角由-0.07改为-0.12弧度。

- 真实分岔点击、跨省边界、连续长时间驾驶仍未完成完整可见浏览器验收；核心分岔/跨节点由确定性测试覆盖。
- 未完成手机真实触摸设备验收、远程GitHub Pages发布与真实断网服务恢复验收；超时/降级由相关逻辑测试覆盖。
- 最后降低视点的效果待用户刷新试用；未宣称已完成该参数的视觉验收。
- 地形不是铁路纵断面，站房、桥梁等仍是平面影像，车辆/道床为简化表现；坡道取值受地形精度影响。
- 初始车尾来路存在歧义时，不虚构分岔路径，可能暂时只显示有确定路径的车辆。已加载省份暂不自动卸载。
- 没有站间导航、时刻表、真实信号/限速、精细车辆和完整空气制动模型。

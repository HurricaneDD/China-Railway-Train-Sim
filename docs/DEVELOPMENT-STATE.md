## 未完成 / 已知限制

- 桥隧仍只是 OSM 标签，不是结构检测或真实纵断面；隧道没有单独光照/洞口模型，桥梁不改变高程。
- 1,722 个几何孤立端点未逐个核对；其中可能仍有 >2 m 的原始缺口或跨省断点。检查页的“邻近未接入”会把平行站线、立交交叉等一并列出，需人工判断。
- 检查页只显示当前加载数据；不加载邻省时省界断点可能误报。加载邻省后本次会话不能卸载，仍会参与边界判定。
- 检查页底图来自 Esri 在线瓦片，离线或服务不可用时自动显示提示并回退到深色网格；不内置离线瓦片缓存，也没有坐标纠偏开关（因为线路是 WGS84，不应纠偏）。
- 2D Canvas 检查页未做断点聚合/聚合展开，省域缩放下红/橙点可能重叠；触摸缩放与超长省份性能未验收。
- 20× 下坡度/邻省检查/自动保存按真实时间节流，长距离高速行驶时地形坡度会滞后；不改变真实铁路纵断面边界。
- 未完成真实长途驾驶、真实移动设备触摸和真实 GitHub Pages 线上验收。

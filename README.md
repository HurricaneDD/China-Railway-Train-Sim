# 国铁列车驾驶模拟器

Vue 3 + TypeScript + Vite + CesiumJS 的纯前端自由驾驶 demo，使用中国铁路分省地理数据。默认驾驶室前向视角，可切换第三人称自由/固定视角；存档保存在浏览器本地。

开始页不显示三维地球，背景为 `media/index/04-trunk-lines.png`，全屏铺满并保留左侧深色渐变；移动端使用更强的暗色遮罩。Cesium 仍在后台加载地图瓦片与地形，进入新游戏后直接复用；三维地图默认使用高德卫星瓦片，可在设置中切换高德卫星（带路网）、高德街道或 Bing 卫星。背景图是静态装饰，不代表当前路网或时刻。

## 本地运行

使用 Node.js 22 或兼容的新版本：

```bash
npm ci
npm run dev
```

```bash
npm test        # 核心逻辑测试
npm run build  # 类型检查、构建并复制运行数据
npm run preview
```

不要跨操作系统复用 node_modules。Cesium 子依赖通过 overrides 与锁文件固定兼容版本。地形通过 Cesium ion 后台加载；三维影像默认来自高德在线瓦片，Bing 卫星为可选影像源，Bing 失败时临时回退高德卫星。失败时可用基础地球继续并重试，公开前端运行配置位于 src/config.ts。

## 数据与部署

运行按需读取 data/geojson/ 下的 33 个分省文件，不读取全国合并文件。超过 GitHub 单文件限制的 data/cnrailway.geojson 不纳入 Git，已有本地副本不受影响。数据字段、来源和许可见 [data/README.md](data/README.md)。

仓库包含 GitHub Pages Actions 工作流。仓库设置中将 Pages Source 设为 GitHub Actions 后，推送 main 会触发构建部署。应用使用相对 base，支持仓库子路径。

## 线路人工检查

新增只读检查页 `dev/railway-check/`，按省读取当前正式 GeoJSON，用红色标出存在被过滤连接的断点、橙色标出邻近未接入、灰色标出孤立端点，并显示桥梁/隧道区段和弱连通分量。检查页可切换高德普通/高德卫星底图；高德瓦片为 GCJ-02，线路与车站数据仍是 WGS84，只在显示时按 GCJ-02 配准，详情和导出保持 WGS84。放大到瓦片 12 级后显示有坐标车站及站名。开发环境访问 `http://localhost:8062/dev/railway-check/`；生产构建输出 `dist/dev/railway-check/index.html`。详细说明见 [检查页 README](dev/railway-check/README.md) 和 [拓扑规则](docs/RAILWAY-TOPOLOGY.md)。

桥隧只由 OSM 标签 `bridge === 'T'` / `tunnel === 'T'` 识别，不做结构检测。2026-11-02 修正了共享端点因桥隧/`layer` 标签差异被误断的问题；江苏实测弱连通分量由 469 降至 100，但仍有站场尽端、原始缺口等孤立端点需要人工核查。

## 当前状态

Demo 0.2 开放全国已有数据的车站出发与地图选点；新游戏先在中国省级行政区划图（兰伯特投影，支持滚轮/按钮缩放与拖动）上点选省份，选定后显示带真实下载/解析进度的全屏加载提示，再进入该省地图预览。三维地图默认使用高德卫星瓦片，高德 GCJ-02 影像在本地配准到 WGS84 后叠加，车站和线路原始坐标不变。选省概览和驾驶中都会在三维车站圆点上方显示 16 px 悬浮站名，站名自动补“站”（如“北京南站”）；驾驶时只在列车 20 km 内生成车站实体，圆点与站名共用 11.2–14 km 距离淡出带，最多 60 个防重叠标签。车站出发会打开车站周边线路图：可直接点击线路并选择地理方向，也可用“最近线路”快捷出发；线路图支持高德卫星/街道底图和滚轮/按钮/移动端双指缩放，底图为 GCJ-02，线路显示时转换配准。数据无法判定上下行，界面只显示“向东北/向西南”等地理方向，不生成站场或股道编号。原始 GeoJSON 不修改；程序按原始共享位置续接，遇分岔主动选择。机车为 20×3.3×4.7 m 长方体，提供驾驶室、第三人称自由和第三人称后方/前方视角（固定视角支持单指转向、滚轮/双指捏合调高）、编组跟随、驻车、暂停、保存恢复及导入导出。驾驶界面采用窗口式布局：顶部 macOS 风格菜单（设置、视角、操作说明、暂停与保存），左侧控制栏（速度/运行状态、牵引、制动、换向、鸣笛/撒砂），底部显示距离、运行时间、省份、线路和最近车站；模拟速度位于顶部菜单栏“视角”之后，支持 1× / 2× / 5× / 10× / 20× / 30× / 50×，便于人工检查线路。分岔和线路中断仍会暂停。

起步：松开驻车，用 Shift/Ctrl 或滑杆调整牵引；按住 Space 制动，松开后缓解。P/Esc 暂停，停稳后可换向。最近线路不一定是正线；线路重叠时可放大或使用快捷出发。可以自由探索，也可完成“行驶 1 km 后停稳”的练习。

全国开放不代表每个任意路线均已验收。地形不是铁路纵断面，站房等仍为平面影像，车辆和道床为简化表现。具体检查结果与边界见 [Demo 验收记录](docs/DEMO-ACCEPTANCE-2026-11-02.md)。
